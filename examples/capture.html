WHIP Capture Demo

Capture webcam or screen and publish to MediaMTX via WHIP

Usage

  • Camera - Capture from webcam with selectable devices
  • Screen - Capture display, window, or browser tab
  • VU Meter - Shows audio level in real-time
  • Mute - Toggle video/audio independently
  • Publish Path - Stream path on MediaMTX server
  • WHIP - WebRTC-HTTP Ingestion Protocol

HTML

<feedboard-capture
  server="http://localhost:8889"
  publish-path="/webcam"
></feedboard-capture>

Programmatic Use

import { WhipClient, captureCamera, captureScreen, getDevices } from 'feedboard'

// List available devices
const { cameras, microphones } = await getDevices()

// Capture camera
const stream = await captureCamera({
  videoDeviceId: cameras[0].deviceId,
  audioDeviceId: microphones[0].deviceId,
})

// Or capture screen
const screenStream = await captureScreen(true) // true = with audio

// Publish via WHIP
const client = new WhipClient('http://localhost:8889/webcam/whip')
await client.publish(stream)

// Disconnect when done
client.disconnect()
